## Project Overview
This portfolio shows how a Business Analyst can use generative AI for prompting, writing, information processing, planning, and verification. All examples are tied to one fictional scenario: piloting an internal Expense Approval System (EAS).

## Selected Workplace Scenario
Business Analyst supporting a 4-week pilot rollout of a fictional internal Expense Approval System.

## Key Learnings
1. Structured prompts prevent AI from guessing missing details.
2. Every AI output needs checking against the original source before use.
3. Missing owners/dates should be labeled [Not Specified], never invented.
4. Final decisions stay with a human, not the AI.
